# 桌面版本地数据与首次使用

安装后打开应用，在「设置」填写 HTTPS Base URL、模型 ID 和密钥，点「保存到 .env」。不需要数据库连接串、会话所有者 UUID、数据库服务或手动迁移。问答仍使用配置的联网模型；仅在本地证据和玩家条件满足时发起模型调用。资料库不是通用游戏百科。

默认提供薇斯纳 7.1 的入门配队摘要，注明来源和适用限制，不包含整篇原文、伤害排行、装备要求或操作顺序。可从首页选择这个问题，再确认版本和真实持有名单；不从推荐阵容推定玩家库存。虚构演示仍单独提供，不自动代替真实问答。

| 数据 | 位置与生命周期 |
| --- | --- |
| 内置攻略 | 安装目录随程序交付的 `desktop_guides.sqlite3`，以只读方式打开。安装包构建仅从项目中明确选入的摘要生成，不读取业务库或用户文件。 |
| 会话与本地 UUID | `%LOCALAPPDATA%\TeyvatNotes\conversations.sqlite3`，应用首次启动创建。重复启动、更新安装包或切换模型不会生成新 UUID。 |
| 模型设置 | `%LOCALAPPDATA%\TeyvatNotes\.env`，安装程序仅在缺失时放置不含密钥的模板，不覆盖已有文件，卸载也不删除。应用保存后密钥位于本机配置文件，勿将其纳入 Git 或分享。 |

可以在关闭应用后备份本地会话文件。若发现数据库损坏或由更高版本创建，应用会提示并保留原文件，不重置或降级数据库。过去的 PostgreSQL 数据库、测试库和 CLI 配置未改变；旧会话不自动合并进桌面本地库，仍可用原 CLI 和原会话所有者标识访问。若不再需要旧库，应先核对具体数据库、调用方和备份，再单独处理。
